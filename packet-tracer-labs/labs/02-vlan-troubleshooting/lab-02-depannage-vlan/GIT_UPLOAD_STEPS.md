# Upload Steps

Use these commands from your terminal.

```bash
git clone https://github.com/Fluffywolf1913VS/network-labs-.git
cd network-labs-

# Copy the generated README.md, screenshots/, and configs/ into:
# packet-tracer-labs/labs/02-vlan-troubleshooting/lab-02-depannage-vlan/

git status
git add packet-tracer-labs/labs/02-vlan-troubleshooting/lab-02-depannage-vlan/README.md
git add packet-tracer-labs/labs/02-vlan-troubleshooting/lab-02-depannage-vlan/screenshots/
git add packet-tracer-labs/labs/02-vlan-troubleshooting/lab-02-depannage-vlan/configs/
git commit -m "Document VLAN troubleshooting lab"
git push origin main
```

If GitHub asks for authentication, use your GitHub username and a Personal Access Token instead of your password.
