# Final DHCP Scope

| Setting | Value |
|---|---|
| DHCP Service | On |
| Network | `192.168.1.0/24` |
| DHCP Server | `192.168.1.20` |
| Start IP | `192.168.1.100` |
| Subnet Mask | `255.255.255.0` |
| Maximum Users | `100` |
| Default Gateway | `0.0.0.0` |
| DNS Server | `0.0.0.0` |

This lab has no router, so the clients only require local LAN connectivity.
