# Lab 02 - Commands Used

## Client Commands

```text
ipconfig
ping 192.168.1.20
```

## Switch Verification

```text
enable
show vlan brief
show interfaces trunk
```

## Troubleshooting Workflow

```text
1. Inspect DHCP server interface
2. Verify DHCP service is enabled
3. Verify LAN DHCP pool
4. Identify missing server IPv4 address
5. Configure server as 192.168.1.20/24
6. Renew DHCP leases on clients
7. Verify client addresses
8. Ping 192.168.1.20 from each client
```
