# Lab 03 - Commands Used

## Client Verification

```text
ipconfig
ping 192.168.1.20
```

## Switch Verification

```text
enable
show vlan brief
show interfaces trunk
```

## Troubleshooting Workflow

```text
1. Compare successful and failed DHCP clients
2. Identify APIPA addresses on PC2 and PC3
3. Inspect the DHCP scope
4. Find Maximum Number of Users = 3
5. Increase the scope capacity to 5
6. Align the built-in serverPool configuration
7. Restart the DHCP service
8. Renew PC2 and PC3 leases
9. Verify 192.168.1.4 and 192.168.1.5
10. Ping the DHCP server from both clients
```
