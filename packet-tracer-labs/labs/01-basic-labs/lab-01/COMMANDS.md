# Lab 01 - Commands Used

## Client
```text
ipconfig
ping 192.168.1.20
```

## Switches
```text
enable
show vlan brief
show interfaces trunk
```

## Workflow
1. Identify APIPA.
2. Check DHCP service.
3. Verify server reachability with a temporary static IP.
4. Review DHCP pools.
5. Configure a clean scope.
6. Renew leases.
7. Validate connectivity.
