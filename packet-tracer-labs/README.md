# Packet Tracer Labs

This section contains Cisco Packet Tracer labs focused on networking fundamentals, VLANs, DHCP, routing, troubleshooting, password recovery, and traffic flow analysis.

## Lab Categories

| Category | Description |
|---|---|
| 01 Basic Labs | Introductory Packet Tracer labs |
| 02 VLAN Troubleshooting | VLAN misconfiguration and troubleshooting labs |
| 03 IP Troubleshooting | IP addressing and connectivity troubleshooting |
| 04 DHCP & VLANs | DHCP and VLAN practice labs |
| 05 Routing Troubleshooting | Routing troubleshooting scenarios |
| 06 Network Down | Network outage troubleshooting |
| 07 Password Recovery | Cisco password recovery practice |
| 08 Traffic Flows | Hub, switch, and traffic behavior analysis |

## Objective

The objective of this repository is to document my learning path in networking and show how I approach troubleshooting scenarios step by step.
