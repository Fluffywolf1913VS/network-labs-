## How to use this folder

1. Download the matching `.pkt` lab from the course resources.
2. Complete the lab in Cisco Packet Tracer.
3. Save your completed file in this folder.
4. Change `[ ]` to `[x]` in this checklist.
5. Add notes or screenshots to document what you learned.
